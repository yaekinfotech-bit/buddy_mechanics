BuddyMechanic - build your APK in the cloud (free)

1. Create a free account at github.com and make a new repository (name: buddymechanic).
2. Upload ALL files from this folder to the repository, including the hidden ".github" folder
   (Add file > Upload files). On Windows/Mac you may need to show hidden files first.
3. Open the repository's "Actions" tab. If asked, click "I understand my workflows, enable them".
4. Choose "Build APK" > "Run workflow". Wait about 5 minutes.
5. Open the finished run and download "BuddyMechanic-APK" (a zip containing app-debug.apk).
6. Send app-debug.apk to your phone, open it, and allow "Install unknown apps" when asked.

Note: this is a debug APK for testing. A Play Store release needs a signed release build.
